# Workstream lifecycle and archived worktrees

After a workstream exists, the user can rename, pin and archive it from its sidebar context menu. Archiving stops its goals and ends its sessions quietly: each session row goes `idle` with `endedAt` set, its log gains no event, and restoring doesn't resume it. <!-- src: crates/hyprlayer-core/src/runtime/workstreams.rs:1866 --> A folder or in-place workstream leaves its files where they are; an isolated or existing worktree moves to `archived-contexts/`. The Archived worktrees popover, reached from the header gear, lists every archive with size, age and PR state. From it the user can filter, restore (reopening the workstream on its latest session), delete or purge merged archives. In a git project, the New workstream dialog also picks the mode (new branch in a worktree, an existing branch in a worktree, or `My checkout`) and the branch type prefix.

## Sub-features

- `ws-rename` renames a workstream from `Rename workstream…`.
- `ws-pin` pins and unpins a workstream into the sidebar's Pinned section.
- `ws-archive` archives a workstream from `Archive workstream…`.
- `arch-open` opens Archived worktrees from the gear popover.
- `arch-filter` filters by text and by `Merged`.
- `arch-restore` restores a workstream and navigates to it.
- `arch-delete` deletes an archive after confirmation.
- `ws-git-modes` covers git-project creation: `New branch` (isolated), an existing branch (`New worktree` or `My checkout`), and `Type of work` prefixes.

## Gotchas

- `list_workstreams` needs both `projectPath` and `includeArchived`. `list_archived_workstreams` and `get_bootstrap` take no args. <!-- src: src/lib/bindings.ts:41 --> <!-- src: src/lib/bindings.ts:65 -->
- Project paths are canonicalised (`/var/folders/…` becomes `/private/var/folders/…`), so take `projectPath` from `get_bootstrap().projects[].path`, not the `$TMPDIR` spelling. This applies to `[data-project-path=…]` selectors and every IPC arg. <!-- src: crates/hyprlayer-core/src/runtime/projects.rs:745 --> <!-- src: src/routes/Root.tsx:1307 -->
- Folder workstreams have no `Attach PR…`, and no board card context menu. <!-- src: src/routes/Root.tsx:1617 --> <!-- src: src/routes/ProjectPage.tsx:1342 -->
- The gear popover and Archived worktrees close while the server is disconnected. <!-- src: src/features/settings/SettingsButton.tsx:30 -->
- The Restore button is disabled when `archiveExists` is false. A folder archive is always `true`. <!-- src: src/features/archive/ArchivedWorktreeRow.tsx:82 --> <!-- src: crates/hyprlayer-core/src/runtime/workstreams.rs:2465 -->
- If the original path is taken, restore fails with `restore_target_occupied` and opens `Restore <branch> elsewhere`, whose path field defaults to `<path>-restored`. <!-- src: src/features/archive/ArchivedWorktreesPopover.tsx:143 --> <!-- src: src/features/archive/RestoreTargetDialog.tsx:26 -->
- A failing archive script shows `Retry` plus `Skip script & archive`. <!-- src: src/features/workstreams/ArchiveWorkstreamDialog.tsx:46 --> <!-- src: src/features/workstreams/ArchiveWorkstreamDialog.tsx:54 -->
- `Purge merged` renders only when the popover has rows, and stays disabled without merged, unkept archives. A folder workstream never has a merged PR. <!-- src: src/features/archive/ArchivedWorktreesPopover.tsx:282 --> <!-- src: src/features/archive/archiveStatus.ts:109 -->
- With `archiveOnMerge` on, a git workstream archives itself when its PR merges. <!-- src: src/routes/Root.tsx:598 -->
