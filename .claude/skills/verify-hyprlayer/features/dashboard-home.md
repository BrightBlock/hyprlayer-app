# Home dashboard, first-run blank and setup wizard

Home (`/`) has three faces. With zero projects it is a first-run blank: `Open a project`, `Clone a repository`, `Connect a server`. With projects it is the Observatory, with a greeting, a status line, the knowledge graph, search, stat pills, and the `Live now` and `Latest activity` panels. It is the first-run Observatory with a `Get set up` pill when the shared CLI config has no thoughts repo. The four-step setup wizard (`/onboarding`: Your name, Hyprlayer CLI, AI agents, Thoughts) runs on its own only when the CLI config is missing. Settings › General › `Re-run setup` always reaches it.

## Sub-features

- `home-first-run` shows the zero-project blank and its three actions.
- `home-observatory` shows the greeting, status line, stat pills and panels once a project exists.
- `home-activity` lists active and archived workstreams in `Latest activity`; `View all →` opens Archived worktrees.
- `home-start-agent` opens New workstream on the most recent project from `Start an agent`.
- `home-discover` opens the Discover repositories dialog.
- `onb-open` opens the wizard from Settings › `Re-run setup`.
- `onb-steps` walks Your name → Hyprlayer CLI → AI agents → Thoughts with Back/Next and the progress strip.
- `onb-exit` leaves via `Exit setup`, Esc, or `Keep current setup`.

## Gotchas

- Onboarding state lives in the shared CLI config, `~/Library/Application Support/hyprlayer/config.json`. Its path has no per-identifier or env override, so an isolated profile sees the user's real config state. <!-- src: crates/hyprlayer-core/src/env.rs:123 -->
- The auto-redirect fires only when `config.state === "missing"`. <!-- src: src/routes/Root.tsx:533 --> `Finish setup`, `Get set up` and the sidebar's `Setup required.` link need no thoughts repo configured. <!-- src: src/features/dashboard/FirstRunBlank.tsx:71 --> <!-- src: src/routes/Dashboard.tsx:351 --> <!-- src: src/routes/Root.tsx:1187 --> The Add project dialog's `Your name` field also needs a missing config. <!-- src: src/features/projects/AddProjectDialog.tsx:489 --> On a configured machine none of these are reachable without editing the user's config: report them unreachable, never fake them.
- `Set up` calls `init_thoughts_repo` and rewrites the shared config. `Repair installation`/`Repair setup` run `hyprlayer ai reinstall` in a terminal. Install methods run a package manager. None of these are safe to click. <!-- src: src/routes/Onboarding.tsx:255 --> <!-- src: src/routes/Onboarding.tsx:122 -->
- `Exit setup` sets a module-level `onboardingDismissed`, which suppresses the auto-redirect until reload. <!-- src: src/routes/onboardingState.ts:3 -->
- Don't hard-code the greeting name, document count, links or graph. They come from the shared config and thoughts index.
- `GraphPins` are `hidden` below the `lg` breakpoint, so a narrow window shows no pins. <!-- src: src/features/dashboard/Observatory.tsx:197 -->
- Global shortcuts (`nav.*`, `project.open`) are swallowed while on `/onboarding`. <!-- src: src/routes/Root.tsx:741 -->
