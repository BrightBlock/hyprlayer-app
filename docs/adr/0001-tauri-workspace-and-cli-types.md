# ADR 0001: Tauri 2 + core crate; re-declare CLI config types

**Status:** accepted · 2026-06-12 · amended 2026-07-05 (enforcement wording: there is no CI —
releases are built locally by design; named the real gates instead) · amended 2026-08-30
("thin shell" now describes the target architecture ADR-0008 enforces, not the pre-refactor
tree)

## Decision

- The app is **Tauri 2** (Rust core, React 19 + TypeScript frontend), structured as a Cargo
  workspace. The target shape, enforced going forward by ADR-0008: `hyprlayer-models`
  (dependency-light shared contracts) → `hyprlayer-core` (all application logic, exposed
  through a `HyprlayerRuntime` facade, zero Tauri deps) → `src-tauri` (a thin IPC shell —
  transport, command DTO mapping, and the desktop-only integrations ADR-0008 names as
  carve-outs). This is the direction the workspace is moving in, not a description of a
  tree that has always looked this way: `src-tauri` historically carried real application
  transactions (project provisioning, document concurrency, provider/session orchestration,
  workstream lifecycle) alongside its IPC shell, and `hyprlayer-models` does not exist until
  ADR-0008's plan reaches its second phase. See ADR-0008 for the full graph, the type-ownership
  rules, and the phase-by-phase command-module disposition.
- IPC contract is generated by **tauri-specta** into `src/lib/bindings.ts`; the bindings file is
  committed and regenerated by `cargo test`. Enforcement is local (no CI by design — releases
  are built on the dev machines via `scripts/release.sh`): a drifted bindings file shows up as
  an uncommitted diff after `cargo test`, and the pre-release flow runs
  `cargo test` + `pnpm typecheck && pnpm lint && pnpm test` before any build.
- The hyprlayer CLI's config types (schema v4) are **re-declared** in
  `hyprlayer-core/src/config/types.rs`, not imported: the CLI is a binary-only crate
  (no `lib.rs`) and drags clap/dialoguer/vendored-OpenSSL. Fixture round-trips in
  `hyprlayer-core/tests/fixtures/` guard against upstream drift, and a version peek fails loudly
  on schema > 4.

## Consequences

- Core logic tests run headless without a webview (macOS locally; Windows on the
  release builder over SSH).
- When upstream extracts a `hyprlayer-types` crate, `config/types.rs` is drop-in replaceable.
- `time` is version-capped in `src-tauri/Cargo.toml` (cookie 0.18.1 coherence breakage with
  time 0.3.48) — remove when tauri's dep tree moves.
