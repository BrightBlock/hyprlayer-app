# ADR 0001: Tauri 2 + core crate; re-declare CLI config types

**Status:** accepted · 2026-06-12

## Decision

- The app is **Tauri 2** (Rust core, React 19 + TypeScript frontend), structured as a Cargo
  workspace: `crates/hyprlayer-core` (all logic, zero Tauri deps) + `src-tauri` (thin IPC shell).
- IPC contract is generated by **tauri-specta** into `src/lib/bindings.ts`; the bindings file is
  committed and regenerated by `cargo test` (CI fails if it drifts).
- The hyprlayer CLI's config types (schema v4) are **re-declared** in
  `hyprlayer-core/src/config/types.rs`, not imported: the CLI is a binary-only crate
  (no `lib.rs`) and drags clap/dialoguer/vendored-OpenSSL. Fixture round-trips in
  `hyprlayer-core/tests/fixtures/` guard against upstream drift, and a version peek fails loudly
  on schema > 4.

## Consequences

- Core logic tests run headless on all three CI OSes without a webview.
- When upstream extracts a `hyprlayer-types` crate, `config/types.rs` is drop-in replaceable.
- `time` is version-capped in `src-tauri/Cargo.toml` (cookie 0.18.1 coherence breakage with
  time 0.3.48) — remove when tauri's dep tree moves.
